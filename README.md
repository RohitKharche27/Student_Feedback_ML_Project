# Student_Feedback_ML_Project

https://studentfeedbackmlproject-fsqurayuhehjodalcvvkmh.streamlit.app/

A Flask-based ML app using a trained Naive Bayes model (Student_model.pkl) to predict feedback from inputs like age, salary, and experience. The model is loaded with Pickle, and app.py handles routes for real-time predictions. Easy to extend and ideal for learning ML deployment.
